## 한국어

이 프로젝트는 한국의 장기 기온변화를 분석하면서, 어떤 결론을 믿을 수 있는지도 함께 검증한 플랫폼입니다. 공식 관측소 목록을 실제 자료 품질로 선별하고 NASA 격자자료와 KMA 지점관측을 비교했습니다. 공통기간 51 <!-- fact:common_n -->개 지점에서 평균기온 상승 방향은 일관됐습니다. 하지만 공간군집이나 상승 크기는 분석기간과 표현 방법에 따라 달라졌습니다. 이 차이를 숨기지 않고 격자 중복, 다중검정, 모형 실패를 별도로 점검했습니다. 최종 보고서와 대시보드의 숫자는 원본 결과의 행·열까지 추적할 수 있습니다. 강건한 발견과 조건부 발견을 구분한 결과를 GitHub v1.1.0 Release와 로그인 없이 읽는 Streamlit 공개 데모로 전달했습니다.

## English

This project examines long-term temperature change in Korea and asks which conclusions survive methodological checks. It connects quality-screened KMA observations with NASA POWER grids in a reproducible Python pipeline. Across the 51 <!-- fact:common_n -->-station common-period network, mean-temperature trends consistently increased. However, spatial clustering and trend magnitudes depended on the period and representation. I present grid sharing, multiple testing and numerical model failures as part of the evidence, not as details to hide. Every quantitative finding in the final report is linked to a saved source row and column. I published the v1.1.0 GitHub release and deployed a public Streamlit demo that distinguishes stable findings from conditional ones, without claiming causal attribution or future prediction.
